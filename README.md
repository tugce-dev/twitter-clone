**# Twitter Clone

A Twitter-inspired social media feed built with vanilla JavaScript. Users can create tweets, like and retweet posts, and view replies through a dynamically rendered interactive feed.

## Features

- Create and publish new tweets
- Like and unlike tweets
- Retweet and undo retweets
- Show and hide replies
- Add new tweets to the top of the feed
- Generate a unique ID for each new tweet
- Dynamically update the feed after user interactions
- Automatically clear the input after publishing

## Technologies & Concepts

- HTML5
- CSS3
- Vanilla JavaScript
- DOM Manipulation
- Event Delegation
- ES6 Modules
- Template Literals
- `data-*` Attributes
- Arrays and Objects
- `forEach()`
- `filter()`
- `unshift()`
- Web Crypto API (`crypto.randomUUID()`)

## What I Practiced

This project helped me practice building an interactive application using vanilla JavaScript without relying on a frontend framework.

I worked with event delegation to handle interactions on dynamically rendered elements, updated object state based on user actions, rendered interfaces from JavaScript data, worked with nested objects and arrays, and connected DOM elements to their corresponding data using unique identifiers.
